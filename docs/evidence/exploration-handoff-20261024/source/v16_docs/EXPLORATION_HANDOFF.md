# 探索吞吐与Frontier目标交接

本轮以已提交的探索v15为基线，在相同场景、NavFn/RPP、SLAM配置、速度与安全保护下比较v16。探索版本号与STM32固件版本分开：固件源码仍为v131、设备最后确认v127，本轮未连接硬件。

## 交接开销的依据

对历史v14办公室的真实事件与里程计复核，28次目标结果到下次发目标的间隔累计100.481仿真秒，中位数3.5755秒，其中98.773秒符合近静止判据。在95%→98%参考观测区间，26.904秒近静止分别关联到前沿搜索11.962秒、Nav2路径查询阶段9.073秒、等新地图3.042秒、导航阶段2.329秒、结果派发等待0.498秒。这些是事件阶段与速度样本的时间关联，不是CPU测量。查询阶段也可能包含回调调度和旧版状态节流。

原状态机只有目标动作返回后才搜索下一批前沿，搜索发起、结果处理和规划结束后的派发又共享1秒节流；每条路径重复计算同批地图安全膨胀与同一终点的可见性。历史依据保留于[诊断JSON](evidence/exploration-handoff-20261024/analysis/historical_v14/diagnosis.json)，本轮性能另以新的v15仿真实验为基线。

## v16实现

接近当前目标0.8米且已收到行驶中新地图时，在一个后台线程中预备一次前沿搜索；起点暂用当前目标位置。预备阶段只计算几何候选，当前Nav2导航照常运行。目标成功后，结果最多保留6仿真秒，要求属于刚结束的同一目标、实际位置与预备起点相差不超过0.15米、实际起点位于快照的0.37米安全通行区；否则重新搜索。

目标成功后，如果当前地图比发目标时更新、收到该图不超过1仿真秒、并且全部指定未知格已经成为已知，就直接记录已有的真实观测，免除再等一帧的空等；任何指定目标仍未知、越界或缺失时，继续等到达后的新地图。实际Nav2查询从刚读取的机器人位姿和朝向出发。观察点、指定未知格的可见性、路径停车末段仍在发目标前按最新地图复查。预备搜索的空结果不能触发完成判定，必须使用最新地图独立复核。取消、导航失败、暂停、输入陈旧和结束都丢弃预备结果。

预备候选的未知格先通过世界坐标转换到最新地图，剔除已经观测的指定目标，再用最新地图进行访问记忆过滤和路径末段检查。地图扩张时不能直接沿用旧格编号，也不能拿旧地图回滚刚记录的访问背景。候选预计大区面积仍来自最多六秒前的短时预备快照，属于排序启发式；真实观测数和最终覆盖另行实测。

原来跨所有状态共用的1秒节流改为仅限制空结果的重复搜索；已完成的异步计算与动作响应在下一次0.2墙钟秒状态循环中处理。到达后的固定0.2仿真秒等待由新地图条件代替。行驶期间继续刷新生命周期就绪证据，避免到达后才发现旧证据过期；三秒时效和显式恢复重新确认保持。

每批只计算一次0.40米观察安全区域，同一候选且完全相同终点的可见性检查可复用；每条不同路径进入到达容差的末段仍逐点检查。专门回归验证同终点的另一条贴障末段仍被拒绝。Nav2路径查询保持串行，并且只在当前导航动作结束后发起；不会与正在执行的行为树争用ComputePathToPose。

单目标到达时仍执行Nav2原有的收速与到达判定。本轮减少上层交接空等，不扩大到达容差、不让探索器发速度，也不把未到达或未观测的目标记成成功。

## 衡量方法

新增`pipeline.csv`记录状态机阶段、地图版本、后台搜索和路径查询状态、就绪等待及墙钟回调间隔。`frontier_search_started/finished`记录从搜索发起到结果被状态机消费的真实间隔；已完成的预备结果可能等待当前目标结束，因此该间隔不等于纯计算时间或CPU耗时。`planning_batch_finished`记录整批查询的实际间隔。旧日志不能补造这些新字段。

近静止使用原始里程计区间，判据为`|v|<0.02 m/s`且`|w|<0.05 rad/s`。超过1仿真秒或时间倒退的间隔不补点、不推断静止。新旧共同的阶段归因根据相同事件规则计算，阶段归因不等于CPU归因。目标交接间隔为动作结果到下一次实际发送目标；零散低速段另按持续至少0.5仿真秒统计，只称运动学近静止段，不冒充控制器显式停车指令。

吞吐比较使用固定几何参考的90%→95%、90%→98%、95%→98%区间，要求连续三次实际地图更新达到阈值。归一化参考面积吞吐为固定阈值之间的参考面积除以实测用时，不等于精确新增激光光束面积。目标数、整场耗时和整场路程作为辅助指标；目标拆分更多或提前partial不自动算更快。最终已知、已知自由和几何误差分别评价。

实验按[预设协议](evidence/exploration-handoff-20261024/source/protocol_v16.json)串行运行，输出目录、ROS域和Gazebo分区独立。单场景一对样本不构成统计显著性或实车结论。最终数据与全部失败见[本轮证据](evidence/exploration-handoff-20261024/README.md)及[验收正文](ACCEPTANCE.md)。

首个办公室基线的早期阶段曾与本机构建和软件检查重叠，实验室基线早期有一次约0.7秒的定向单测；完整测试和绘图在运动实验结束后再执行。因此本轮按真实记录报告工程样本，不宣称严格资源受控或统计显著的A/B性能结论。
