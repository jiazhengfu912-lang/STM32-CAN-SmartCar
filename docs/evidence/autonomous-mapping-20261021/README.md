# 陌生环境自主探索建图 · 2026-10-21（仅仿真）

已经接通从空白地图开始的“自动选观察点→Nav2移动避障→SLAM更新→继续探索→停车保存”流程。**不需要键盘驾驶或人工Nav2 Goal；实车桥尚未实现。** [操作说明](../../AUTONOMOUS_MAPPING.md)

最终办公室运动版本自动发30个目标，29个到达；第30个因本轮600仿真秒预算到期取消，持续停车并保存四件套，明确标记`TIME_LIMIT_PARTIAL / complete=false`。不能把本次结果说成所有未知区域均已覆盖。新入口默认预算900仿真秒，用户可以配置有限正数。

## 地图质量单独检查，不以面积增长代替

占据格中心与原SDF障碍表面的距离在固定初始map/world坐标基准下离线计算，未拟合配准、未剔除异常，占据阈值65；地图分辨率5cm。SDF仅用于验收对照，没有交给探索器、SLAM或规划器作为先验。

| 版本 | 占据格数 | 表面距离中位数 | P95 | ≤0.15m支持比例 |
|---|---:|---:|---:|---:|
| 早期room_03 | 2616 | 0.353m | 2.819m | 45.83% |
| 早期office_01 | 5901 | 0.191m | 1.391m | 47.06% |
| 调整后office_02 | 4070 | 0.0258m | 0.142m | 97.30% |

这些是**仿真几何代理指标，不是地图准确率、全部障碍召回率、物理精度或预设合格分数**。它们反映早期地图确有明显偏差，不能因运行检查PASS就说地图质量通过。降低建图运动/转向速度、筛掉过短前沿、检查长前沿多个位置及区分通行/观察余量之后，本次组合方案明显改善；未做单变量因果隔离或统计显著性试验。

## 失败和实现演进

全部13次运行及逐轮源码/日志均保存，[总表](trials.json)区分运行结果、会话原因、目标数和完成标志。

- room_01：嵌套launch误继承导航的`params_file`，SLAM没有得到正确配置；中断本测试并保留日志，改为显式传SLAM参数。
- room_02：Humble的ClockType导入位置不兼容，探索器启动失败；修正为本机rclpy.clock接口。任务进程退出会关闭本次仿真组。
- room_03：自动移动、增长和保存检查PASS，但两个目标失败、一个启动阶段目标被拒，地图质量偏差明显，结果为部分地图。随后等完整生命周期active再发首个目标。
- office_01：31个自动目标全部到达，最终当前位置不满足选择器较严的观察余量后保存部分图；质量仍不理想。调整为与Nav2现有0.37m圆一致的通行区域，观察目标额外要求0.40m已知自由圆，并采用较慢建图运动、0.8m前沿阈值及多代表点搜索。
- watchdog_01：失联停车和锁存有效，但恢复进程时旧输入触发了结束保存，未进入预期暂停状态；改为输入中断先暂停，必须显式恢复。watchdog_02后通过。
- watchdog_03：所有停止/恢复检查通过，SLAM自带图片保存返回255；日志为map_saver内部2秒订阅等待失败。保留该失败，不重复覆盖原文件。
- 最终保存修正：建图模式增加独立`map_saver_server`，瞬态本地订阅在线地图，10秒只读保存等待；图结构仍由SLAM序列化。watchdog_04和complete_room均验证四件套；随后用最终保存接口输出完成重载导航。仅保存等待改变，运动保护不放宽。[同版Nav2保存器源码](https://github.com/ros-navigation/navigation2/blob/1.1.20/nav2_map_server/src/map_saver/map_saver.cpp)

各运行的`source/`用于定位当时真正执行的版本；`source_current/`保存最终源码。**office_02验证最终运动/几何方案；其后改图片保存接口并增加建图专用RViz显示，最终接口由watchdog_04、complete_room和map_reload_final_writer分别验证。** 不把不同阶段统称同一个实测版本。初始归档脚本之后追加了最终接口重载、分析和文档；最终文件清单以SHA256为准。

## 交付和边界

- 新入口：`ros2 launch smartcar_nav2 exploration.launch.py world:=office_loop rviz:=true`；不预载office_01、不启动AMCL/map_server，SLAM唯一发布地图和map→odom。
- 探索器只发送导航目标，不发布速度；任务心跳按墙钟，失联后门控停车/取消/锁存，恢复心跳不解除锁存；暂停、显式继续和结束保存见操作说明。
- 观察目标0.40m圆必须已知自由，通行圆与原Nav2一致为0.37m；不穿过未知/墙体。受阻目标记忆和有限恢复防止无限往返，不自动清图。
- `NO_FRONTIERS`、受阻部分地图、时间预算、人工提前结束、异常均分别记录；部分地图不会被标记为完全探索。遮挡、过窄通道、动态障碍和漂移仍可能限制探索。
- 用户原窗口未重启或发送目标。所有试验在非86域、随机独立Gazebo分区内进行；最终自建进程无残留。未访问硬件、未实现实车桥、固件/协议/控制台及原场景模型未改，未提交/推送/合并。
- [office_02新地图](runs/office_02/mission/map.yaml)与同目录PGM/posegraph/data原样保留；[完整房间的最终接口输出](runs/complete_room/mission/map.yaml)同样可用。新入口每次新建地图，跨启动的自主探索续接尚未加入。
