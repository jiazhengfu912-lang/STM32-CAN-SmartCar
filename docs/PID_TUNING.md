# PID 调试记录导航

当前为**速度PI（D=0）**，并非已完成整车PID整定。STM32输出CAN电流命令，C610执行电流控制；本页是导航，全部原始波形、失败段和数据解释见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## v125 参数与单位

来源：[drive.c](../firmware/stm32_app/Core/Src/drive.c)、[drive.h](../firmware/stm32_app/Core/Inc/drive.h)。

| 项目 | 当前值 |
|---|---|
| 比例P | 右轮反转0.45；左轮双向、右轮正转0.30 |
| 稳态I | 每控制周期0.010 × 电机轴转速误差 |
| 低速启动I | 5–10 rpm轮速且尚未起转时0.030；每拍增量限幅±6 |
| D | 0（未实现微分项） |
| 控制周期 | 标称10 ms；实测诊断存在10–13 ms间隔 |
| 速度单位 | 内部电机轴rpm；页面轮速为其除以36 |
| 测速 | 8192刻度角度展开、约30 ms差分；预热/间隔过长时回退原始RPM |
| 启动释放 | 同方向达到1 rpm轮速，削减过大积分；一般输出上限150，右轮低速反转180 |
| 再启动 | 已退出启动后，连续100 ms低于约0.5 rpm重新进入启动保护 |
| 限幅 | 启动输出450；积分±1200；总输出±2000（电流命令原始量） |

I是每拍系数，代码没有再乘dt；不能直接当作每秒积分增益复制到其他控制周期。两轮积分独立；启动释放上限不是强制最小电流，也不是固定前馈。精确边界以源码为准。

## 版本演进与结论

| 版本 | 调参或算法变化 | 实测结论/边界 |
|---|---|---|
| v101–v110 | 早期P/I、积分释放试验 | 历史记录保留，不能替代当前版证据 |
| v111–v113 | 捕获积分/起转细节，核对编码器角度测速 | 逐步区分控制与测量问题 |
| v114 | 角度差分速度进入真实闭环 | 测速方法改变，跨版本噪声不能直接比较机械性能 |
| v115–v117 | 对称PI、起转输出限制与重复验证 | 有改善示例，启动差仍存在 |
| v118–v119 | UART/心跳排查、停转后重新启用起转保护 | 通信与控制性能分别记录 |
| v120 | 启动I提升至0.030，稳态I保持0.010 | 起步等待缩短，五轮中一轮运行不稳，整体未通过 |
| v121 | 仅右轮反转P 0.30→0.45 | 首轮全运行区间未改善；短时重复趋稳，低速反向超调仍大 |
| v122 | 释放阈值1→0.5 rpm，P/I不变 | 重复中再次停转，提前释放方案否决 |
| v123 | 恢复1 rpm阈值，P/I同v121 | 12 rpm双向各20秒较稳，不能外推低速/落地 |
| v124 | P/I及控制不变，冻结首256拍控制周期诊断 | 发现起转后支撑不足与超调并存 |
| v125 | P/I不变；仅右轮低速反向释放上限150→180 | 复测仍二次启动；网页停止正常不等于速度环通过 |

## 最新证据

以下为已有v125复测，不是本次仓库整理新增试验。P：右轮反转0.45→0.45，其余0.30→0.30；I：稳态0.010→0.010、启动0.030→0.030；D=0。v125控制改变仅为上述释放上限150→180，旨在提高起转后支撑。

![v125复测起步控制周期记录](evidence/v125-retest-startup-20260919/v125_startup_trace.png)

256条有效控制周期、CRC错误0。右轮210 ms起转，360 ms再次进入启动；释放上限提高未消除停转。第一次起转积分尚小，上限基本没有执行削减，因此不能继续只靠提高上限解释或解决问题。

![v125复测完整运动与停止](evidence/v125-retest-20260919/v125_trial_02.png)

5 rpm后退6秒，新运动段故障0、UART错误0，停止后目标/速度/输出0；累计CSV保留上一轮故障。起步3秒后标准差不能掩盖启动失败。
